SUJIT KUMAR KAPAR — E-PORTFOLIO WEBSITE

Files:
- index.html: Website content
- style.css: Layout, colors, and responsive styling
- script.js: Mobile navigation and current year

HOW TO VIEW:
1. Extract the ZIP file.
2. Open index.html in a web browser.

IMPORTANT PERSONALIZATION:
- Check every skill and remove anything you do not know.
- Replace the two suggested project outlines with projects you have actually completed. Do not claim the sample projects as your own.
- Add your real email, phone, location, GitHub, and LinkedIn links.
- Add only certifications and achievements you have earned.
- Add your resume as resume.pdf in the same folder to activate the Download Resume link.
- Add screenshots of your real projects if available.

GITHUB PAGES:
1. Sign in to GitHub and create a new public repository (for example: sujit-portfolio).
2. Upload index.html, style.css, and script.js to the repository's main branch.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
5. Wait for GitHub Pages to publish the website. The published URL will appear in the Pages settings.
